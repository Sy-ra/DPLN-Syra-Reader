DPLN Syra Reader

Installation sur Windows avec le navigateur Chrome · environ 5 minutes, une seule fois, rien d'autre à installer.

Ce que fait l'app : quand tu ouvres un guide sur dofuspourlesnoobs.com dans Chrome, il s'affiche dans une petite fenêtre verticale que tu peux garder au-dessus du jeu. Chaque coordonnée devient un bouton 36,-44 qui copie /travel 36,-44, et F8 copie le trajet suivant même quand tu es en jeu.

Contenu du dossier

DPLN Syra Reader - pour Chrome ├── Tuto - à ouvrir en premier.html ← ce fichier └── DPLN Syra Reader ├── 1 - Installer.bat ├── DPLN Syra Reader (raccourci, créé par l'installeur) ├── Extension Chrome ← dossier à charger dans Chrome └── (fichiers de l'app, ne pas toucher)
Avant de commencer Place le dossier DPLN Syra Reader - pour Chrome à un endroit où il restera, par exemple dans Documents. Ne le laisse pas dans le zip ni dans Téléchargements, sinon l'extension et le raccourci ne marcheront plus si tu le déplaces ou le supprimes.

Si tu l'as reçu en .zip : clic droit sur le zip → Propriétés → coche Débloquer en bas → OK, puis clic droit → Extraire tout…

1Installer l'app

  1. Ouvre le dossier DPLN Syra Reader.
  2. Double-clique sur 1 - Installer.bat. Une fenêtre noire s'ouvre et télécharge le moteur de l'app (environ 100 Mo, 1 à 3 minutes).
  3. Quand elle affiche « C'est installé ! », appuie sur une touche pour la fermer. Un raccourci DPLN Syra Reader (l'icône du chat) est apparu sur ton Bureau et dans le dossier.
Windows affiche « Windows a protégé votre ordinateur » ? C'est normal pour un fichier qui ne vient pas d'un éditeur connu. Clique sur Informations complémentaires puis Exécuter quand même.

2Installer l'extension dans Chrome

C'est elle qui prévient l'app quand tu ouvres une page dofuspourlesnoobs.

  1. Dans Chrome, tape chrome://extensions dans la barre d'adresse et valide.
  2. En haut à droite, active Mode développeur.
  3. Clique sur Charger l'extension non empaquetée (en haut à gauche).
  4. Va dans DPLN Syra Reader - pour Chrome → DPLN Syra Reader, sélectionne le dossier Extension Chrome (un simple clic dessus) et clique sur Sélectionner un dossier.
  5. La carte « DPLN Syra Reader – Pont » apparaît. Vérifie que son interrupteur est bien activé.
Erreur « Fichier manifeste absent ou illisible » ? Tu as choisi le mauvais dossier. Il faut sélectionner Extension Chrome lui-même (celui qui contient manifest.json), pas le dossier au-dessus.

3Lancer et tester

  1. Double-clique sur le raccourci DPLN Syra Reader du Bureau.
  2. Dans Chrome, ouvre un guide, par exemple Requiem pour un Yokai.
  3. La page s'affiche dans l'app avec le message « Page ouverte depuis le navigateur ». 🎉

Place la fenêtre où tu veux (sur un 2e écran par exemple) : elle se rouvrira au même endroit.

?Dépannage

La page ne s'affiche pas dans l'app

  • L'app doit être ouverte avant d'ouvrir la page dans Chrome. Sinon, recharge l'onglet (F5) ou change d'onglet et reviens.
  • Vérifie dans chrome://extensions que « DPLN Syra Reader – Pont » est activée.
  • Solution de secours sans extension : copie l'adresse de la page (Ctrl+L puis Ctrl+C), l'app l'ouvre toute seule.
  • Au démarrage, Chrome peut proposer de désactiver les extensions en mode développeur : ferme le message (ne clique pas sur Désactiver) pour la garder active.

F7 / F8 ne font rien en jeu

  • Une autre appli utilise peut-être déjà ces touches : change-les dans ⚙ → Raccourcis.

Le raccourci du Bureau ne marche plus

  • Tu as sûrement déplacé le dossier. Relance 1 - Installer.bat depuis son nouvel emplacement, et recharge l'extension dans Chrome depuis le nouveau dossier.

↻Mettre à jour

  1. Ferme l'app.
  2. Remplace le contenu du dossier DPLN Syra Reader par la nouvelle version (garde le dossier runtime, sinon relance 1 - Installer.bat).
  3. Dans chrome://extensions, clique sur ↻ sur la carte « DPLN Syra Reader – Pont ».
